# Yukun-Guo.github.io

Personal site: https://yukun-guo.github.io

This is a static GitHub Pages homepage (`index.html` at the repo root). A `.nojekyll` file tells GitHub to publish the HTML as-is.

On GitHub Free, the repository must be **public**. If it is private, https://yukun-guo.github.io returns GitHub's "There isn't a GitHub Pages site here" 404 even when Pages builds succeed. Change visibility under **Settings → General → Danger Zone → Change repository visibility → Public**, then wait for Pages to rebuild.
